# Health Connect Codelab

This repository contains a codelab to help you get started writing [Health Connect][health-connect] apps for Android. This codelab guides you through the process of integrating Health Connect into your Android application, allowing you to read and write health and fitness data.

## Setup

You will need:

*   An Android device or emulator running API level 27 or greater. You can check the API level in the device's settings or through Android Studio.
*   The [Health Connect APK][health-connect-apk] installed on the device or emulator (for Android 13 and lower). If the link is outdated, you can search for "Health Connect APK" online or find it on platforms like APKMirror.

## Getting started

This sample uses the Gradle build system. To get started:

1.  Open the project in Android Studio using "File > Open".
2.  Build the project by selecting "Build > Make Project" or using the "gradlew build" command in the terminal.
3.  Run the application on a connected device or emulator by selecting "Run > Run 'app'" or clicking the "Run" button in the toolbar.
